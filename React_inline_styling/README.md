# React Inline Styling

This project focuses on styling React applications using inline styles and Aphrodite.

## Learning Objectives

- Understand the differences between CSS files and inline styling
- Use Aphrodite to style React components
- Apply conditional styles in JavaScript
- Implement responsive design
- Use media queries with Aphrodite
- Create animations with Aphrodite

## Tasks

- Task 0: Inline styling
- Task 1: Aphrodite
- Task 2: Conditional styling
- Task 3: Responsive design
- Task 4: Animation

## Technologies

- React
- JavaScript
- Aphrodite
- Jest
- Enzyme
- Webpack
