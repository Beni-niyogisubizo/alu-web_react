# React State

This project contains five progressive React exercises focused on component state, controlled forms, React Context, and React Hooks.

## Tasks

### Task 0: Notification Drawer
Manage the notification drawer's visibility using React component state.

### Task 1: Controlled Login Form
Implement controlled email and password inputs, form validation, and submit-button state.

### Task 2: React Context
Manage authentication in App and share the current user and logout function through React Context.

### Task 3: Context Consumer and Notification State
Display a Contact us link for logged-in users and remove notifications from App state when marked as read.

### Task 4: React Hooks
Use the useState hook to select and deselect course rows, updating their background colour.

## Running the Application

Navigate to the final dashboard:

    cd react_state/task_4/dashboard

Install dependencies:

    npm install

Start the development server:

    NODE_OPTIONS=--openssl-legacy-provider npm start

Run the tests:

    npm test -- --watchAll=false

## Technologies

React, JavaScript, React Context, React Hooks, Jest, Enzyme, Webpack, and Aphrodite.
