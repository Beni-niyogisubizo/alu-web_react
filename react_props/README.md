# React Props

This project covers React props and component development.

## Learning Objectives

- Create reusable React components
- Pass data to components using props
- Validate props using PropTypes
- Define reusable PropTypes shapes
- Render lists of components using loops
- Use keys when rendering lists
- Test React components with Jest and Enzyme
- Use React Developer Tools and the Profiler

## Tasks

- Task 0: Basic components
- Task 1: Component tests
- Task 2: NotificationItem component
- Task 3: React Developer Tools and Profiler
- Task 4: PropTypes and CourseList
- Task 5: Shapes, loops, and keys
