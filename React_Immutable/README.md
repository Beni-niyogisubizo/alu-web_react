# React Immutable

This project introduces immutable data structures in JavaScript using the Immutable.js library.

## Learning Objectives

- Understand immutable objects and why immutability is useful.
- Convert JavaScript objects into immutable data structures.
- Understand the differences between Immutable List and Map.
- Access nested values using getIn.
- Use merge, concat, and deep merging.
- Compare immutable objects using is.
- Work with lazy sequences using Seq.

## Tasks

| File | Description |
|------|-------------|
| 0-fromjs.js | Convert an object using fromJS |
| 1-map.js | Convert an object using Map |
| 2-nested.js | Access nested elements |
| 3-list.js | Create and update immutable Lists |
| 4-mutations.js | Perform chained Map mutations |
| 5-merge.js | Concatenate Lists and merge Maps |
| 6-deeply.js | Merge nested objects |
| 7-equality.js | Compare Immutable Maps |
| 8-seq.js | Filter and format students using Seq |
